# ADR-0019：個別使用者的模型權限

- 狀態：已採納
- 日期：2026-10-08
- 依據：使用者要求特定人員可開放系統未開放的模型，或停用系統已開放的模型；延伸 ADR-0016。

部署模型與 LiteLLM AllowedModels 交集仍為可配置上限。系統開放清單改為每位使用者的預設；管理員在「使用者」逐模型選擇依系統設定、允許或不允許。未覆寫的模型動態繼承系統設定，明確允許可超出系統開放清單，但不得超出部署上限。允許個人全部停用；無可用模型時拒絕執行。有效預設優先採系統預設，否則取個人生效清單第一個。

沿用 platform.system_settings，key 為 vibemaker.user_model_access.{userId}，JSON 只保存覆寫模型 ID 與布林值，不新增資料表或 migration。空覆寫刪除該設定；部署移除模型後忽略其舊覆寫；損毀個人設定不回復全域權限，直到管理員儲存或還原。不存在的使用者回 404。

GET/PUT/DELETE /api/admin/users/{userId}/models 套用 Admin 與 XSRF 保護，變更與還原寫稽核。GET /api/models、送訊息、排隊執行啟動及 virtual key 都用個人生效清單，不快取權限。排隊中模型被禁止則失敗；已開始的執行繼續，下一次執行換發限模型 key。前端存檔後與回到前景時刷新模型選單。
