# 前端網站託管、發布與分享開發計畫

- 記錄日期：2026-10-07
- 狀態：**後續開發計畫；尚未實作**
- 已確認需求：使用者建立前端網站後，可發布成可開啟的網站；存取方式包含公開、公司內部及指定使用者；發布後可管理分享名單。
- 本次只記錄計畫，不變更程式、資料庫、網站服務或 Cloudflare 設定。

## 目標與目前差距

目前 `/make` 的「網站系統架設」會指示 Pi Agent 整理需求、規劃頁面及資料結構，於使用者的 workspace 建立程式並提供 README。檔案介面支援查看原始內容及下載，但沒有網站發布、網址分配或分享權限功能。

新增獨立的前端網站託管區，讓成果從「可以下載的程式碼」變成「可以透過網址使用的網站」。網站服務獨立於 Agent 執行環境，Agent 任務結束、容器閒置停止或重建，都不應中斷已發布網站。

第一版支援單一 HTML、多頁靜態網站及 React／Vue／Angular 建置後的靜態產物。需要後端、資料庫、伺服器端渲染或長駐 Node 程序的應用，另列部署計畫；前端託管不代表提供資料庫或可靠的多人資料儲存。

## 使用流程與權限

1. 使用者在對話或專案中要求建立網站；Agent 在自己的 workspace 開發，並產生可發布的前端檔案。
2. 使用者從成果介面選擇「發布網站」，確認網站名稱、產物目錄、網站類型（一般靜態網站或 SPA）及存取方式。
3. 平台檢查來源擁有者、檔案邊界及產物，建立發布版本；成功後提供穩定網址與「開啟網站」按鈕。
4. 後續修改需再次發布才更新線上版本；發布失敗保留目前可用的版本，並提供可理解的失敗原因及重試方式。
5. 擁有者可變更存取方式、加入／移除分享對象、取消發布，以及查看發布狀態。取消發布後網址不再提供網站內容，原始碼及 workspace 保留。
6. 被分享者可在「分享給我的網站」查看仍獲授權且已發布的網站。

| 存取方式 | 存取條件 |
|---|---|
| 公開 | 不需登入，任何取得網址的人都可開啟 |
| 公司內部 | 經入口驗證的有效公司身分，且對應未停用的 Ymir 使用者 |
| 指定使用者 | 登入後對應未停用的 Ymir 使用者，且為網站擁有者或分享名單成員 |

分享對象首版限已存在的 Ymir 使用者，以平台 user ID 保存授權，不以可變動的姓名或 email 作為授權依據。選擇器只提供辨識分享對象所需的顯示名稱與識別資訊，不開放使用者管理資料。公司內部模式不自動接受所有本機帳號，企業身分與租戶範圍須在設計階段明確定義。

首版分享只有「瀏覽」權限。分享不授予原始碼下載、workspace 存取、Agent 操作、編輯、發布或分享管理權限。擁有者以外的管理員操作另依平台管理政策定義，不默認具備瀏覽所有私人網站的權限。

移除分享、停用帳號、取消發布或把公開改成私人後，後續請求必須依新權限驗證；已下載至瀏覽器的內容無法回收。轉傳網址不會把存取權一起轉給他人。網站內的業務資料授權仍由其後端負責，不能用「看得到前端」取代 API 授權。

## 建議架構與安全邊界

```text
使用者對話 → API／Pi Agent → 使用者 workspace（原始碼與建置產物）
                                ↓ 擁有者要求發布
                    發布服務：驗證、複製版本、切換目前版本
                                ↓
                    獨立託管目錄 → Nginx 靜態網站服務
                                        ↑
訪客 → Cloudflare Tunnel → 網站存取入口（公開／公司／分享名單）
```

- 新增獨立的 Nginx 託管容器，首版共用服務並按網站及版本分組，不為每個靜態網站啟動 Agent 或獨立應用容器。容器僅以唯讀方式掛載發布產物，不掛載原始 workspace、agent-state 或容器管理 socket。
- 使用獨立於 Ymir 平台的網站網域，每個網站使用獨立 hostname，避免不同網站共用 localStorage／Service Worker 等來源狀態。實際網域、DNS、TLS 與 Tunnel 路由是啟用前的部署前置條件；不得直接把不可信 HTML 放到 Ymir 登入網域的路徑下。
- 採固定的託管入口與受控路由，網站 ID 由平台產生，不接受使用者任意指定主機、轉送位址或主機路徑。沿用 [ADR-0006](../adr/0006-cloudflare-tunnel-public-edge.md) 的對外入口方向，但需新 ADR 設計使用者網站隔離。
- 僅複製明確選定的靜態產物快照；不把 `.env`、原始碼、憑證、套件目錄或 agent-state 當成網站內容。需定義允許檔案類型、單站檔案數／容量及每人網站配額；拒絕路徑穿越、symlink 逃逸及未完成的產物。
- 建置指令在使用者 Agent 環境執行，託管服務不執行使用者指令；發布服務不得執行使用者提供的 shell 指令。受控的產物複製由主機服務負責，保留 [ADR-0008](../adr/0008-containerized-api-runtime-host.md) 的 API／runtime host 邊界。
- 公司內部及指定使用者網站的 HTML、JS、CSS、圖片與所有其他資源，都必須經存取驗證；底層 Nginx 不得有可繞過入口的公開連接埠或 URL。私人內容不得被公共快取提供給未授權者。
- 私人網站入口沿用 Ymir 的身分來源與帳號停用政策，但使用專屬、限 hostname 的 HttpOnly session cookie，禁止把 Ymir 平台 cookie、IdP token 或其他站台 session 交給網站腳本。跨網域登入接回與短效單次票據的細節需以新 ADR 設計及測試，不能只信任前端宣稱的 user ID。
- 擁有者發布、取消發布、存取模式變更與分享名單變更需驗證擁有者、antiforgery 並寫稽核。錯誤摘要不得暴露 host 路徑、機密或原始指令輸出。

## 預定資料與介面

這些是後續設計的最低需求，不代表目前已存在的 API 或資料表。

| 資料 | 需記錄的內容 |
|---|---|
| 網站 | 網站 ID、擁有者、來源專案／對話、名稱、穩定 hostname、存取模式、SPA 設定、目前發布版本與狀態 |
| 發布版本 | 網站 ID、版本 ID、來源相對目錄、受控產物位置、建立時間、發布者、處理狀態與錯誤摘要 |
| 分享授權 | 網站 ID、被分享的 Ymir user ID、授權者及時間；同一網站／使用者不得重複 |

- 擁有者介面：我的網站、建立／重新發布、查看結果、取消發布、更新存取模式及管理分享名單。
- 接收者介面：搜尋可分享的使用者，以及列出「分享給我的網站」；不因此取得所有帳號或其他人的 workspace 資料。
- 網站入口：依 hostname 找到網站，驗證發布狀態與訪客權限，再提供檔案；未知網站、未發布網站及無權限情境不能洩漏內容。
- 一般多頁網站保留檔案路由；SPA 支援頁面路由回到 `index.html`，但不存在的 JS／CSS 等資源必須回 404，不能誤回 HTML。
- 相同網站的並行發布需序列化；採完整版本建立後再切換，避免訪客讀到混合版本。首版預留失敗版本清理及保留上一成功版本作為恢復依據。

## 後續開發階段與驗收

| 階段 | 工作及完成條件 |
|---|---|
| 1. 架構與部署設計 | 新 ADR：獨立網站網域、每站來源隔離、私人網站登入與資源驗證、主機產物複製介面、容量／數量／版本保存限制；完成 DNS／Tunnel 前置設定清單 |
| 2. 靜態網站發布 | 建立網站及發布版本、產物檢查、Nginx 託管、穩定網址、SPA 路由、原子版本切換及取消發布；先驗證公開網站 |
| 3. 身分與分享 | 公司登入模式、指定使用者授權、分享選擇器與「分享給我的網站」；驗證撤權及停用帳號 |
| 4. 對話成果整合 | 在成果介面加入發布操作及結果連結，完善錯誤提示、稽核、重啟恢復、版本清理與部署操作文件 |

驗收至少包含：

1. 單一 HTML、多頁網站及 SPA 可以透過網址開啟，資源及直接進入子頁面都正常。
2. Agent 停止／重建不影響已發布網站；修改 workspace 不影響線上版本，重新發布成功才切換。
3. 建置／複製失敗、超過容量及並行發布不破壞目前版本；服務重啟後可辨識未完成版本並安全恢復。
4. 公開網站無需登入；公司模式拒絕不符公司條件的身分；指定模式僅擁有者及名單成員可看。
5. 被分享者不能管理、重新發布或取得來源檔案；擁有者無法發布／分享其他人的成果。
6. 移除分享、停用帳號、取消發布及公開改私人後，直接資源連結與快取均不能繞過新權限。
7. 網站腳本無法讀取平台 session 或另一網站的來源儲存；登入接回、票據重放及跨站請求防護通過測試。
8. 路徑穿越、symlink、未知 hostname 及含機密檔案的錯誤產物遭拒；底層服務不可從外網直接繞過入口。
9. 網站服務隨主機／Docker 重啟恢復；發布產物納入備份，稽核不含憑證或敏感內容。

## 實作前仍需確認

- 使用者網站的實際網域與控制權、DNS／TLS／Tunnel 路由，以及公司限定模式涵蓋的租戶／帳號。
- 每人網站數、單站容量、發布版本保存及網站／來源封存後的保存規則。來源封存不得直接刪除已發布產物，需明確告知是否繼續提供服務。
- 網域與存取權的 ADR 完成後再實作；本計畫不更動現有 Ymir Tunnel，也不把 Agent 容器改成長期網站服務。
- 本功能不依賴 [OneDrive Workspace 計畫](onedrive-workspace-plan.md)；日後可從本機同步副本發布，發布版本與 OneDrive 同步狀態仍分開管理。
