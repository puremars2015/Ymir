# 簡報建置指引

先確認主題與目的、聽眾、使用情境與講述時間、頁數、來源資料、版型與品牌色；已提供的需求不重複詢問。先提出每頁大綱，使用者確認後再產生可編輯 `.pptx`。

映像預裝 `python3-pptx`，使用系統 `python3` 的 `from pptx import Presentation`，無須建立 npm 專案。腳本、來源資料與中間檔使用 `.ymir/tmp/`；只有最終簡報放入 system prompt 指定的本次 `deliverables/{executionId}/`。預設只交付 PPTX，不額外交付腳本、套件設定或 PDF，除非使用者要求。

預設 16:9、繁體中文，字型使用 Noto Sans CJK TC。使用可編輯文字與形狀，圖片不得代替整頁文字；每頁聚焦一個重點，減少長段落，保持一致標題、色彩、留白及對比。數據、引用、名單、日期均以使用者資料為準；缺少資料要詢問，不編造數字。

使用 python-pptx 檢查頁數、文字、圖片與形狀邊界是否落在頁面內；確認無重疊、截斷或空白投影片。需要視覺驗證時使用部署環境可用的簡報渲染工具，無渲染工具時如實說明；不要把僅有大綱的文字檔冒充 PPTX。
