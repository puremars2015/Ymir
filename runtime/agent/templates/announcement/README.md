# 公司公告 Word 模板

從使用者提供的活動公告保留公司 Logo、橫幅、表格版面、淺藍背景、頁面框線、字型與頁尾；原始活動內容、姓名、信箱及作者資訊已移除。原始檔案不修改，也不收進映像或版本庫。

頁面沿用範例的 16840 × 20979 twips，四邊留白 567 twips，並非 A4。以 Word 開啟可編輯；本機使用 LibreOffice 渲染驗證。長篇公告可跨頁，應檢查分頁並避免單頁塞入過多內容。

正文列取消原始固定的最小高度，改由內容自然延伸並靠上排列，避免短公告留下大片空白；深藍頁尾的聯絡文字改為白色，提升可讀性。其他頁面與品牌樣式沿用原始範例。

## Agent 使用方式

先確認公告目的、發布單位、日期、正文／名單、對象、聯絡窗口及風格。缺少的事實先詢問，未提供的選填內容留空；範例資料不是預設事實。

1. 參考 `example.json`，把確認後的資料寫到 `.ymir/tmp/announcement.json`。
2. 執行 `python3 /opt/ymir/templates/announcement/build.py .ymir/tmp/announcement.json <本次成果目錄>/公告.docx`。
3. 檢查成品的文字與段落；可用 `python3` + `zipfile`／`lxml` 讀取 DOCX。只有最終 `.docx` 放進成果目錄，JSON、腳本及模板留在工具／暫存位置。

## 欄位

| 欄位 | 說明 |
|---|---|
| `department` | 必填發布單位，模板自動加上「公告」 |
| `title` | 必填公告主旨 |
| `date` | 公告日期文字，可留空 |
| `sections` | 至少一段，可依內容增減，不固定前三名或抽獎格式 |
| `sections[].heading` | 段落標題；需要編號時由內容提供 |
| `sections[].body` | 內文，支援換行 |
| `sections[].items` | 選填條列項目，不限制原始範例的人數 |
| `closing` | 選填結語 |
| `contact` | 選填聯絡窗口，可包含使用者確認的聯絡方式 |

建置器只修改 `word/document.xml`，其他模板 package parts 原樣保留；以來源段落複製標題、正文、條列格式，不重建整份文件。不支援的 JSON 欄位會報錯，避免內容被悄悄忽略。
